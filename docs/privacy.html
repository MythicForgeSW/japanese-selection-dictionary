Privacy Policy

Japanese Selection Dictionary · Effective August 2, 2026

This policy describes how the Japanese Selection Dictionary Chrome extension (“the Extension”) handles information. The Extension is published by MythicForgeSW.

What the Extension does

When you select Japanese text on a web page, the Extension may look up that selection and show readings and English meanings in a bubble next to the selection.

Information processed

  • Selected text you choose to look up. The Extension reads text you highlight on the active page only for the purpose of dictionary lookup.
  • No accounts. The Extension does not require sign-in and does not create user profiles.
  • No intentional local vocabulary storage. The Extension does not save a personal word list, browsing history, or account data in extension storage.

Network requests

To fetch definitions, the Extension sends the selected query text to the public Jisho word-search API at https://jisho.org/api/v1/search/words. Jisho’s own privacy practices apply to data it receives.

Page access

The Extension runs on ordinary http:// and https:// pages so it can detect text selections and show the definition bubble. It does not sell page content and does not use page content for advertising.

Data sharing and sale

The Extension does not sell personal information. Selected query text is shared with Jisho solely to return dictionary results. The Extension author does not operate a separate analytics or advertising backend for this product.

Children’s privacy

The Extension is not directed at children under 13, and it does not knowingly collect personal information from children.

Changes

If this policy changes in a material way, the effective date at the top of this page will be updated.

Contact
